# Gate B — PILOT_001 standardized task package

Protocol: `docs/HUMAN_TTFP_BASELINE_PROTOCOL_v1_0.md`
Condition: HUMAN_TRADITIONAL
Purpose: feasibility pilot for reproducible TTFP observation. This pilot alone does not support broad human-vs-HookLab claims.

## Participant eligibility
Participant must have practical preproduction responsibility as producer, arranger, songwriter/composer, or music director. Record primary role, years of experience, principal DAW/tools, and prior familiarity with the task material before timing begins.

## Standardized brief
Create the first usable structural preproduction proposal for an original contemporary Dance-Pop song intended for a mainstream commercial context.

Constraints:
- approximate target duration: 3:00–3:30;
- 4/4 meter unless the participant explicitly justifies another choice;
- energetic, memorable chorus/hook;
- clear contrast between verse and chorus;
- arrangement should be realizable with conventional contemporary production tools;
- this is structural preproduction, not final composition, recording, mixing, mastering, or finished lyric writing.

## Required output contract
The clock stops only when a saved/submitted artifact contains all five items:
1. `section_form_plan` — ordered section/form map;
2. `tempo_metric_recommendation` — tempo and meter recommendation;
3. `harmonic_tonal_recommendation` — key/tonal center and/or harmonic structural recommendation;
4. `melodic_rhythmic_recommendation` — concrete melodic/rhythmic structural recommendation relevant to the hook/target;
5. `production_constraints` — explicit production directions sufficient to begin realization.

## Permitted tools
Conventional tools normally used by the participant are permitted: DAW, instrument, paper, notation software, calculator/metronome, text editor, and personally established workflow aids. Generative HookLab candidates are prohibited before submission. Record every major tool used.

## Timing
`t0`: participant opens this package, confirms readiness, and begins work.
`t1`: first artifact satisfying all five required outputs is saved/exported and submitted.
`TTFP_human = t1 - t0` using continuous wall-clock time. Experimenter-requested pauses are documented and subtracted; participant-initiated task breaks remain included unless caused by an unrelated external interruption.

## Required retained evidence
- raw start timestamp;
- raw stop timestamp;
- elapsed seconds;
- submitted preproduction artifact;
- participant metadata using a pseudonymous ID;
- prior familiarity statement;
- major tools used;
- interruption/pause log;
- admissibility audit against the five required outputs.

## Contamination controls
Do not show HookLab-generated candidates before `t1`. Do not repeat this same task after exposure to HookLab and count the repetition as an independent human baseline. Do not estimate or reconstruct elapsed time after the fact.

## Interpretation boundary
This pilot tests feasibility and provides the first observed Gate-B datum if valid. It measures workflow latency under this bounded task contract; it does not measure artistic quality, creativity, commercial success, or equivalence of final musical outcomes.
